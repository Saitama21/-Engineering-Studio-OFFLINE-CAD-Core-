# Analog Drawing Core v0.9.0

Цель: строить сборочный чертёж из SLDASM в логике эталонного листа пользователя, не копируя PDF как изображение.

## Автоматическая структура листа
- продольный главный вид;
- торцевой вид;
- разрез A–A по осевой плоскости;
- сечение/вид B–B;
- увеличенные зоны C и D;
- два изометрических сборочных вида;
- позиционные выноски;
- BOM/спецификация;
- основная надпись и масштаб.

## Размерная стратегия
- общий осевой габарит;
- цепочки расстояний между крупными торцевыми плоскостями;
- основные наружные диаметры;
- групповые отверстия;
- центр-линии и секущие обозначения.

## Точность
Геометрия пока восстанавливается из SolidWorks FaceTessellations. Это не точный Parasolid B-Rep. Поэтому инженерные размеры помечаются TESS / VERIFY.
