ROZFOOD ENGINEERING STUDIO v1.4.2
LOCAL DRAWING RENDER + FOCUS ZOOM

Главная задача патча: убрать глубокую перерисовку всего тяжёлого чертежа на каждый тик колеса.

1. Локальный рендер тяжёлой геометрии
- Длинные mesh-path автоматически распознаются как тяжёлая геометрия.
- Во время зума полный path временно заменяется облегчённой интерактивной версией.
- При приближении строится только геометрия видимой области с запасом по краям.
- Геометрия вокруг точки курсора получает приоритет детализации; периферия видимой области прореживается сильнее.
- После завершения зума/панорамирования исходный полный SVG path автоматически восстанавливается.

2. Плавность zoom-to-cursor
- События колеса объединяются и применяются один раз на animation frame.
- Зум использует time-based easing вместо ступенчатого изменения viewBox.
- Убрано искусственное падение навигации до 24/30 FPS на тяжёлых листах.
- Тяжёлая локальная геометрия пересобирается реже, чем сам viewBox, чтобы движение оставалось плавным.

3. Панорамирование
- Локальный рендер работает и во время панорамирования.
- После отпускания мыши полный чертёж возвращается автоматически.

4. Читаемость во время навигации
- На тяжёлых листах больше не скрывается весь текст и штриховые элементы только из-за зума.
- Тяжёлые фильтры SVG отключаются на время интерактивного движения.
- На экране появляется небольшой индикатор LOCAL RENDER, когда работает облегчённый режим.

5. Совместимость
- Инструменты «Редактировать / Зум / Панорама» из v1.4.1 сохранены.
- Ручные правки и localStorage-история не меняют формат ключей.
- Полный SVG для экспорта восстанавливается после интерактивной навигации.
- PWA/offline cache и версия приложения обновлены до v1.4.2.

Native Parasolid B-Rep в этом патче не добавляется: сначала стабилизируется производительность и UX больших SLDASM/чертежей.
