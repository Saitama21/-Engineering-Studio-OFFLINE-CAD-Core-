ROZFOOD ENGINEERING STUDIO v1.6.0
SUBASSEMBLY + PRODUCTION DRAWING CORE

1. Геометрия подсборок
- Выбранный SLDASM-узел больше не считается пустой папкой.
- Ядро рекурсивно собирает все дочерние SLDPRT-вхождения.
- Мировая матрица выбранной подсборки удаляется один раз; взаимное положение
  дочерних деталей сохраняется в локальной системе подсборки.
- Лист детали, авторазмеры и Feature Graph получают объединённую геометрию.

2. Выбор в 3D
- Выбор родительской подсборки распространяется на все дочерние componentId.
- В режимах Объём/B-Rep/Каркас вся подсборка выделяется одним объектом.
- Камера вписывает выбранный компонент, а остальная сборка остаётся только
  слабым контекстом.
- В BOM для подсборки показывается агрегированное число граней/shell и число
  дочерних геометрических деталей.

3. Feature Graph
- Добавлен отдельный слой core/feature-graph.js.
- Для осевой детали распознаются: общая длина, основной диаметр, круговая
  ступень по торцевым кольцам, длина ступени и конические переходы/фаски.
- Для крестовины распознаются: ступица, центральное отверстие, толщина,
  три радиальных стержня и повторяющиеся отверстия/PCD.
- На контрольном барабане подтверждено:
  * МКРП-60.01.469: L203, Ø16, ступень Ø10×3,
    две фаски 1×45° и одна фаска 0,5×45°;
  * Хрестовина 1: Ø60, Ø25, толщина 18, 3×Ø16,
    4 отверстия Ø7 на PCD Ø42;
  * Хрестовина 2: Ø60, Ø25, толщина 18, 3×Ø16.

4. Производственный Drawing Planner
- Для длинной осевой детали создаётся книжный лист A4.
- Главный вид ставится вертикально; торец получает отдельное обозначение 3:1.
- Ненужный автоматический A-A для простого стержня удалён.
- Размеры L203, Ø16, Ø10, 3 и сгруппированные фаски формируются из Feature Graph.
- Для крестовины создаётся отдельный профиль CROSS: главный вид по оси
  ступицы, вид сбоку, изометрия и характерные производственные размеры.
- В чертёж выбранного компонента передаётся имя его SLDPRT/SLDASM, а не имя
  корневой сборки.

5. Количество
- Количество берётся только из фактических вхождений текущего SLDASM.
- Внешнее количество производственного заказа не угадывается и не
  подменяется хардкодом, если оно отсутствует в свойствах исходной сборки.

6. Оффлайн
- Cache namespace обновлён до v1.6.0.
- core/feature-graph.js добавлен в обязательный оффлайн-кэш.

Ограничение остаётся прежним: exact Parasolid Surface/Curve не декодируется;
аналитика строится поверх SolidWorks FaceTessellations и явно обозначена как
faceted/verified, а не как нативный Parasolid B-Rep.
