ROZFOOD ENGINEERING STUDIO v1.7.0
REFERENCE A2 ASSEMBLY PLANNER

Исправлено по эталонному PDF «Сборка Барабана Глобино»:

1. Новый профиль DRUM_REFERENCE_A2
   - Геометрически распознаёт барабан по продольной оси, повторяющимся наружным кольцам и непрерывному валу.
   - Формирует лист А2 1684×1191 вместо универсальной раскладки.

2. Планировщик видов
   - B: наружный продольный вид.
   - B: торцевой вид.
   - A: рабочий продольный вид без ложной штриховки окна.
   - C (2:3): локальная объединённая геометрия крестовины, а не весь торец барабана.
   - A–A (1:7): истинные линии пересечения секущей плоскости.
   - B–B (1:5), D (2:5), два изометрических представления.

3. Размерная логика из SLDASM
   - 1225 / 958 / 227 / 40.
   - Цепь 30–279–30–279–30–280–30.
   - Торец Ø476 / Ø461 / Ø345.
   - Крестовина Ø60, четыре отверстия Ø7, PCD Ø42.
   - Локальные признаки D: 61 / 30 / 3 / 2 и сварной шов.

4. Производственная спецификация
   - Верхнеуровневые .SLDASM больше не выводятся как отдельные строки деталей.
   - BOM разворачивается по уникальным листовым SLDPRT и сохраняет фактические количества.
   - Для контрольной сборки: позиция 1 состоит из МКРП-60.01.461.1 и девяти МКРП-60.01.469; далее позиции 2–13.

5. Штамп и свойства
   - Масса извлекается из нативного Contents/CusProps (30,32 кг для контрольного файла).
   - Масса отображается в дереве и основной надписи.
   - Формат А2 и масштаб 1:5 выбираются автоматически.

6. Регрессия v1.6.0 сохранена
   - Рекурсивная геометрия выбранных подсборок.
   - Чертежи «Хрестовина 1», «Хрестовина 2» и МКРП-60.01.469.
   - Feature Graph AXIAL_PART / CROSS_ASSEMBLY.

Ограничение остаётся честным: источник — встроенная SolidWorks FaceTessellations и свойства SLDASM. Ядро строит собственную V/E/F/Shell-топологию, но не объявляет её точным Parasolid B-Rep.
