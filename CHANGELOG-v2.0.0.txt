ROZFOOD Engineering Studio v2.0.0 — Feature Recognition Core Alpha

BASE
- Built from v1.9.0 SLDDRW Reference Reader Alpha.
- Existing SLDASM/SLDDRW import, B-Rep topology, BOM, drawing editor, local zoom rendering and offline PWA behavior retained.

FEATURE RECOGNITION CORE ALPHA
- Hole Recognition Engine: analytically fitted cylindrical holes are classified as through, blind or stepped when the tessellated geometry supports that conclusion.
- Drawing dimensions now include Ø callouts for recognized holes; blind holes can carry depth and stepped holes are marked accordingly.
- Chamfer Recognition Alpha: conservative candidates from small oblique planar faces.
- Fillet Recognition Alpha: conservative candidates from partial-cylinder analytical fits.
- Thread Recognition Alpha: low-confidence candidate only when repeated coaxial cylindrical/ring geometry has a regular pitch. It does NOT invent a thread when tessellation does not support one.

VISIBILITY / DRAWING
- Ordinary main/orthographic/assembly views use a coarse hidden-surface z-buffer so internal components/edges are not drawn through the exterior.
- Sections remain the mechanism for intentionally exposing internals.
- HSR is view-dependent and works on tessellated faces; it is not an exact Parasolid hidden-line solver yet.

SHEET METAL / FLAT PATTERN ALPHA
- Sheet-metal candidates are detected from repeated parallel-plane spacing / thin envelopes plus bend-like partial cylinders.
- Recognized thickness and bend count are shown.
- A new “Развёртка” drawing mode is enabled only for a component recognized as sheet metal.
- Flat pattern dimensions are an engineering ALPHA approximation from tessellated surface area and inferred bend geometry, with K-factor 0.40. VERIFY BEFORE CUTTING/PRODUCTION.

MATERIALS
- Material is read only when present in accessible SLDASM document properties.
- The app does not fabricate per-component materials when they are absent. Exact part material may require SLDPRT/SLDDRW properties or an explicit BOM/specification.

3D SECTION
- Added half-section clipping in the 3D viewer. Button cycles X → Y → Z → off, with the cut plane at 50% of the selected/model bounds.

LIMITATIONS / HONESTY
- Exact Parasolid/NURBS feature history is still not decoded.
- Chamfers, fillets, threads and flat patterns marked α are TESS-derived candidates and require engineering verification.
- Weld semantics are not yet an exact feature class; HSR and cleaner line selection reduce internal/ragged line noise, but true weld-feature recognition is future work.
