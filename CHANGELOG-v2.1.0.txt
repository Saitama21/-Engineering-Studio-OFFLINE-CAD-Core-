ROZFOOD Engineering Studio v2.1.0 — Drawing Reconstruction Core

GOAL
- Primary goal: make the first automatic assembly drawing clean and readable before adding more CAD editing tools.
- The reference drum assembly is treated as a regression target, not as a hard-coded one-off template.

DRAWING RECONSTRUCTION CORE
- Added drawing/drawing-reconstruction-core.js.
- Added welded tessellation edge topology with model-scale adaptive vertex quantization.
- Added engineering edge classification: BOUNDARY / SILHOUETTE / FEATURE / TANGENT / TESSELLATION.
- Coplanar triangle diagonals and gentle curved-surface tessellation edges are suppressed before SVG generation.
- Curved surfaces therefore no longer emit every tessellation seam as visible drawing geometry.

VISIBILITY / HLR 2.1
- Replaced whole-edge keep/drop visibility in renderMesh with segmented edge visibility.
- Occlusion is sampled along each engineering edge, so one 3D edge may become several visible 2D intervals.
- Increased and made adaptive the tessellated depth field resolution.
- This specifically targets torn/ragged linework and lines incorrectly continuing through the drum shell.
- Exact Parasolid/NURBS HLR is still not available; v2.1.0 remains a faceted reconstruction pipeline.

REGRESSION TARGET: DRUM ASSEMBLY
- The automatic sheet continues to use model-derived axial/drum planning, sections, detail views, dimensions and BOM.
- The linework feeding those views is now reconstructed engineering linework rather than raw tessellation-derived edges.
- SVG paths carry reconstruction diagnostics (raw edge count, engineering edge count, visible segment count) for debugging.

PWA
- Application/service-worker/cache version bumped to v2.1.0.
- drawing-reconstruction-core.js is part of the offline cache.

HONEST LIMITATION
- This release is a substantial cleanup of faceted geometry, not a replacement for an exact SolidWorks/Parasolid drawing kernel.
- For production equivalence to a manually authored reference PDF, future work still needs true analytic B-Rep curves/surfaces, exact hidden-line removal, semantic section generation and dimension intent recovery.
