ROZFOOD ENGINEERING STUDIO v2.2.0 — ENGINEERING REFERENCE LIBRARY ALPHA

Goal
- Let the operator select an engineering drawing object and mark it as a reusable reference (эталон).
- Store construction/edit rules, not a bitmap/PDF snapshot.

Implemented
- Drawing Editor now treats reconstructed engineering views and the title stamp as first-class selectable objects in addition to annotations.
- New “★ Сделать эталоном” command in Правка.
- Local reference library stored offline in browser localStorage; no AI, API or cloud.
- Reference record stores semantic signature: role, drawing profile, mode, SVG type, text cue and aspect ratio.
- Reference rule stores operator-approved offsets, visibility, text and tolerances.
- On a compatible drawing, matching reference rules are automatically applied unless the target already has explicit per-drawing edits.
- Reference marks are data-only; no cosmetic changes to the production drawing pipeline.

Scope / honesty
- Alpha matching is semantic/rule-based, not ML.
- v2.2.0 does not yet infer section placement or dimension grammar from a PDF image.
- Geometry reconstruction/HLR remains the v2.1 core; this release intentionally does not change geometry rendering.
