# Drawing Core v0.4.0

## Логика

1. STEP разбирается локально.
2. Recognition Core находит точные цилиндры, окружности, поверхности, PCD и B-Rep границы.
3. Drawing Core оценивает площадь ортогональных проекций и выбирает главный вид.
4. Для тела вращения главный продольный вид автоматически дополняется торцевым видом.
5. Геометрия рёбер проецируется в XY/XZ/YZ без облачного сервиса.
6. Круговые элементы получают центровые линии, диаметры и PCD-выноски.
7. Для деталей вращения концентрические круговые кромки используются для построения продольного A–A и длин ступеней.
8. Чертёж оформляется на листе с основной надписью ROZFOOD ENGINEERING STUDIO и может быть выгружен как SVG.

## Режимы

- **Эскиз** — один главный вид и габариты.
- **Рабочий** — главный + дополнительный вид, габариты и feature callouts.
- **Производственный** — рабочий режим + автоматический A–A, примечания и основная надпись.
- **Контрольный** — максимум проекций и геометрической информации для проверки.

## Важное ограничение

Авточертёж не подменяет конструкторское утверждение. В v0.4.0 автоматизируется геометрическая рутина; технологические требования, допуски, шероховатость и стандарты оформления пока остаются контролируемым слоем.
