# Drawing Core v0.5.0

## Режимы

1. **Каркас** — один основной вид и габариты.
2. **Рабочий** — два вида и основные feature-размеры.
3. **Производственный** — два вида + автоматический разрез для тел вращения.
4. **Контрольный** — до трёх ортогональных видов + разрез.
5. **Сборочный детализированный** — виды сборки + позиционные выноски + BOM.

## Исправление основной надписи

Бренд теперь раскладывается на две строки внутри левой части штампа:

- `ROZFOOD`
- `ENGINEERING STUDIO`

Это исключает наложение на правую колонку `Режим / Единицы / Масштаб / Статус / Ядро`.

## Сборочный режим

Для STEP-сборки:

- экземпляры компонентов берутся из assembly occurrences;
- одинаковые компоненты группируются в одну BOM-позицию;
- позиционные номера привязываются к экземплярам на проекции;
- BOM строится прямо на листе.

Для SLDASM без B-Rep строится BOM-лист на основании Native Reference Adapter.

## Ограничения

Автоматическая спецификация и позиции строятся детерминированно по структуре файла. Посадки, моменты затяжки, технологические требования, ГОСТ/ISO-оформление и semantic PMI должны подтверждаться конструктором.
