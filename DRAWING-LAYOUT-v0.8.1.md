# Drawing Layout Core v0.8.1

Цель релиза — приблизить автоматический сборочный лист к реальному производственному чертежу, используя загруженный пользователем сборочный PDF только как эталон компоновки, а не как фон или шаблон-картинку.

## Сборочный детализированный лист

- лист A2 landscape по пропорциям;
- основной продольный вид;
- второй продольный/секционный вид;
- торцевой вид;
- обозначения A–A, C, D;
- два изометрических сборочных вида;
- автоматические габариты;
- цепочка осевых расстояний по крупным торцевым плоскостям;
- распознанные диаметры и групповые обозначения отверстий;
- позиционные выноски по компонентам;
- спецификация/BOM;
- основная надпись и автоматически выбранный масштаб;
- маркировка TESS / VERIFY до появления точного B-Rep.

## Источник геометрии

Все линии строятся заново из SLDASM FaceTessellations и матриц сборки. Исходный PDF не встраивается в приложение и не используется как графический слой.
