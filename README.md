# ROZFOOD ENGINEERING STUDIO · OFFLINE CAD v0.8.1

## Drawing Layout Core

Эта сборка принимает **только `.SLDASM`** и работает полностью локально: без AI/API, без облачного CAD и без отправки модели на сервер.

### Что добавлено в v0.8.1

- сохранён нативный импорт `SLDASM → COMPINSTANCETREE + FaceTessellations`;
- сохранены матрицы вхождений и корректная сборочная 3D-сцена;
- сохранено TESS-распознавание плоскостей, цилиндров, отверстий и осей;
- полностью переработан режим **«Сборочный детализированный»**;
- добавлен лист пропорций **A2 landscape** с рамкой и основной надписью;
- главный продольный вид строится по распознанным цилиндрическим оболочкам, чтобы не перегружать его внутренней геометрией;
- добавлены второй продольный вид, торцевой вид, обозначение **A–A**, увеличенные детали **C** и **D**;
- добавлены два изометрических сборочных вида из реальной mesh-геометрии;
- автоматически ставятся общий габарит и цепочка крупных осевых расстояний;
- выводятся основные распознанные диаметры и групповые обозначения отверстий;
- добавлены позиционные номера компонентов без длинных пересекающихся выносок;
- BOM/спецификация размещается на листе вместе с основной надписью;
- масштаб выбирается автоматически из стандартного ряда; для контрольной сборки барабана получается **1:5**;
- экспорт SVG сохраняет весь производственный лист локально.

### Контрольный файл

На `Сборка Барабана Глобино.SLDASM` ядро получает:

- 17 BOM-позиций;
- 31 вхождение;
- 28 размещённых leaf-вхождений;
- 117 tess-блоков;
- 25 962 треугольника сборочной сцены;
- габарит около **476 × 1225 × 476 мм**;
- 86 плоских поверхностей;
- 67 цилиндрических поверхностей;
- 36 внутренних цилиндрических поверхностей/отверстий.

На листе автоматически восстанавливается характерная цепочка крупных осевых участков, включая повторяющиеся **30 / 279 / 30 / 279 / 30 / 280 / 30 мм**, и основные диаметры оболочки **Ø476 / Ø470 / Ø467(≈468) мм**.

### Ограничение

v0.8.1 по-прежнему работает по **FaceTessellations**, а не по точному Parasolid B-Rep. Поэтому технологические размеры и автоматически выбранные сечения помечаются **TESS / VERIFY** и должны быть подтверждены конструктором.
