# ROZFOOD ENGINEERING STUDIO · OFFLINE CAD v0.6.2

Локальный импортёр **только для SolidWorks Assembly (`.SLDASM`)**. STEP/STP и отдельные SLDPRT в этой сборке намеренно не принимаются.

## Что работает сейчас

- загрузка `.SLDASM` локально в браузере;
- определение контейнера SolidWorks/CFB;
- извлечение ссылок на компоненты и подсборки;
- подсчёт экземпляров;
- дерево сборки;
- BOM / спецификация;
- режим «Сборочный детализированный» для BOM-листа;
- офлайн PWA и локальный Service Worker.

## Важно про 3D

Текущий модуль является **reference-level SLDASM adapter**. Он не декодирует закрытую B-Rep/тесселированную геометрию SolidWorks. Поэтому полноценная 3D-модель и геометрические размеры из сырого `.SLDASM` появятся после подключения отдельного SolidWorks-совместимого native geometry decoder.

Интерфейс больше не предлагает STEP/STP и не предлагает SLDPRT: архитектура этой сборки — **SLDASM only**.
