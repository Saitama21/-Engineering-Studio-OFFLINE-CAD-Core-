# ROZFOOD ENGINEERING STUDIO · OFFLINE CAD v0.5.0

Локальный CAD/engineering-клиент для STEP и SLDASM: импорт, B-Rep распознавание, размеры, 3D-каркас, автоматический инженерный чертёж и сборочный BOM без AI/API и без серверного CAD.

## v0.5.0 · Drawing Core + Assembly Detail

Главные изменения:

- Исправлена основная надпись чертежа: **ROZFOOD ENGINEERING STUDIO** больше не пересекается с колонкой режима на узком экране.
- Пять режимов чертежа: **Каркас / Рабочий / Производственный / Контрольный / Сборочный детализированный**.
- Новый сборочный детализированный лист для STEP-сборок:
  - главный и дополнительный ортогональные виды;
  - позиционные выноски;
  - автоматическая спецификация/BOM;
  - количество повторяющихся компонентов;
  - сборочные примечания.
- Для SLDASM доступен отдельный BOM-лист в режиме **Сборочный детализированный**, даже когда B-Rep SolidWorks недоступен.
- Добавлена кнопка **«Открыть сборочный чертёж»** во вкладке «Сборка».
- Добавлена дедупликация одинаковых размерных записей.
- Экспорт SVG и JSON-отчёта обновлён до v0.5.0.
- Service Worker cache bump до v0.5.0.

## Что умеет Drawing Core

- Автоматически выбирает наиболее информативный главный вид.
- Для деталей вращения подбирает продольный + торцевой вид.
- Строит XY / XZ / YZ проекции.
- Добавляет центровые и осевые линии для круговой геометрии.
- Ставит габаритные размеры.
- Формирует обозначения диаметров.
- Распознаёт болтовые окружности и выводит `6× ⌀6 · PCD ⌀60`.
- Строит продольный разрез A–A для распознанных тел вращения.
- Штрихует материал в разрезе.
- Извлекает длины ступеней деталей вращения.
- Экспортирует чертёж в SVG локально.

## Сборки

### STEP

Для STEP-сборки ядро читает PRODUCT / NEXT_ASSEMBLY_USAGE_OCCURRENCE / ITEM_DEFINED_TRANSFORMATION, применяет трансформации экземпляров и строит BOM.

### SLDASM

Нативный reference-level адаптер читает OLE/CFB-контейнер, ссылки SLDPRT/SLDASM, количество экземпляров и BOM. Закрытая B-Rep геометрия SolidWorks не декодируется, поэтому геометрические виды/размеры требуют STEP-экспорт.

## Встроенные тестовые модели

- `sample_flange.step` — фланец Ø80 × 12, центральное Ø20, 6×Ø6 на PCD Ø60.
- `sample_shaft.step` — ступенчатый вал Ø36 / Ø30 / Ø20 длиной 90.
- `sample_assembly.step` — плита + 4 одинаковых болта с assembly transforms.

## Важно

v0.5.0 генерирует **рабочий инженерный черновик**, который нужно проверять конструктору. Это пока не автоматически утверждённый ГОСТ/ISO документ.

Пока не реализовано полностью:

- hidden-line removal производственного уровня;
- PMI/GD&T/MBD AP242;
- автоматическое чтение заданных в CAD допусков/шероховатости, если они не присутствуют как поддерживаемые semantic PMI;
- полное распознавание резьб, фасок, канавок и скруглений;
- нативный B-Rep decoder SLDPRT/SLDASM;
- редактирование импортированного feature tree.
