# ROZFOOD ENGINEERING STUDIO · OFFLINE CAD v0.6.0

Локальный CAD/engineering-клиент для STEP и SLDASM: импорт, сборочная 3D-сцена, B-Rep распознавание, размеры, инженерный авточертёж и BOM — без AI/API и без серверного CAD.

## v0.6.0 · Import & Visualization Core

Главное изменение — STEP-сборка теперь не просто читается как список сущностей: ядро разворачивает реальные вложенные трансформации компонентов и строит единую 3D-сцену.

### Что добавлено

- Корректная ориентация STEP assembly relationships через `PRODUCT_DEFINITION` / `SHAPE_DEFINITION_REPRESENTATION`.
- Поддержка вложенных сборок и рекурсивного накопления трансформаций.
- Разворачивание B-Rep геометрии каждого экземпляра в мировые координаты.
- Поддержка `B_SPLINE_CURVE_WITH_KNOTS` с локальной выборкой кривых.
- Корректные дуги окружностей/эллипсов по вершинам и направлению `EDGE_CURVE`.
- Формирование face loops из `ADVANCED_FACE → FACE_BOUND → EDGE_LOOP → ORIENTED_EDGE`.
- Новый 3D-режим **«Объём»** с заливкой граней + каркасом.
- Режим **«Каркас»** для чистой геометрии рёбер.
- Выбор детали кликом прямо в 3D-сцене.
- Выбор компонента из вкладки **«Сборка»** с подсветкой в 3D.
- Декодирование STEP Unicode-строк `\X2\...\X0\`, поэтому русские имена деталей читаются нормально.
- Для реальной сборки отображаются количество компонентов, рёбер и граней именно в сцене, а не только число геометрических определений.

## Drawing Core

Сохраняются возможности v0.5.0:

- пять режимов: **Каркас / Рабочий / Производственный / Контрольный / Сборочный детализированный**;
- главный и дополнительные виды;
- осевые/центровые;
- размеры `Ø`, `R`, PCD, группы отверстий;
- разрезы;
- сборочный BOM и позиции;
- экспорт SVG и JSON-отчёта.

## SLDASM

SLDASM по-прежнему читается локальным reference-level адаптером: дерево ссылок SLDPRT/SLDASM, количество экземпляров и BOM. Закрытая B-Rep геометрия SolidWorks напрямую пока не декодируется — для 3D используется STEP-экспорт.

## Проверка на реальном STEP

v0.6.0 прогнана на предоставленной реальной сборке **«Сборка Барабана Глобино»**:

- 8 286 STEP entities;
- 31 assembly occurrence;
- 28 геометрически отображаемых компонентов;
- 610 рёбер в итоговой 3D-сцене;
- 450 граней в итоговой 3D-сцене;
- габарит сцены примерно **476 × 1225 × 476 мм**;
- русские имена компонентов декодируются;
- вложенные компоненты размещаются в своих реальных позициях.

Исходный пользовательский STEP в дистрибутив не включён.

## Важно

Это собственное лёгкое офлайн-ядро, а не OpenCascade/SolidWorks kernel. Оно уже показывает реальную STEP-сборку и анализирует её геометрию, но пока не является полным промышленным B-Rep kernel.

Пока ограничено:

- точная NURBS-поверхностная тесселяция промышленного уровня;
- hidden-line removal уровня SolidWorks;
- PMI/GD&T/MBD AP242;
- нативный B-Rep decoder SLDPRT/SLDASM;
- редактирование импортированного feature tree.
