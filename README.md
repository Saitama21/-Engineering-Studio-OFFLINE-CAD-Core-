# ROZFOOD ENGINEERING STUDIO · OFFLINE CAD v0.9.0

## Analog Drawing Core

Эта версия строит сборочный лист из нативного `.SLDASM` по инженерной логике эталонного чертежа: продольный и торцевой виды, A–A, B–B, локальные C/D, изометрические виды, позиции, BOM и основная надпись.

Исходный PDF не встраивается в приложение и не используется как фон. Он служит только эталоном логики оформления.

### Точность

Импорт и чертёж работают по SolidWorks FaceTessellations + assembly transforms + аналитическому распознаванию плоскостей/цилиндров/отверстий. Точный Parasolid B-Rep пока не декодирован; такие данные остаются `TESS / VERIFY`.
