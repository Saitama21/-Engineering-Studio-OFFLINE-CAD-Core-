# ROZFOOD ENGINEERING STUDIO · OFFLINE CAD v0.4.0

Модульное офлайн-ядро для чтения STEP, распознавания геометрии и построения инженерного чертежа прямо в браузере. Без AI, без API и без серверного CAD.

## Что нового в v0.4.0 · Drawing Core

- Новый производственный авточертёж вместо простого каркаса.
- Автоматический выбор наиболее информативного главного вида.
- Для тел вращения автоматически выбирается связка **продольный вид + торцевой вид**.
- До трёх ортогональных проекций: XY / XZ / YZ.
- Центровые и осевые линии для круговой геометрии.
- Автоматические габаритные размеры проекций.
- Автоматические обозначения диаметров.
- Болтовая окружность: штрихпунктирный PCD + выноска вида `6× ⌀6 · PCD ⌀60`.
- Автоматический продольный разрез A–A для распознанных деталей вращения.
- Штриховка материала в разрезе и распознавание сквозного концентрического отверстия.
- Длины ступеней деталей вращения извлекаются из STEP-геометрии и появляются в таблице размеров.
- Четыре режима чертежа: **Эскиз / Рабочий / Производственный / Контрольный**.
- Основная надпись с брендом **ROZFOOD ENGINEERING STUDIO**, именем модели, единицами и B-Rep статистикой.
- Локальный экспорт готового чертежа в SVG.
- Новый фирменный PWA-значок ROZFOOD CAD и тот же логотип внутри приложения.

## Что уже работает в ядре

- Локальная загрузка `.step` / `.stp` через File API и drag & drop.
- Парсер ISO-10303-21 с индексом STEP entities.
- B-Rep топология: body / shell / face / edge / vertex.
- LINE, CIRCLE, ELLIPSE, PLANE, CYLINDRICAL_SURFACE, CONICAL_SURFACE, SPHERICAL_SURFACE, TOROIDAL_SURFACE.
- Определение единиц STEP и перевод длины в mm.
- Точные габариты с учётом окружностей/эллипсов.
- Распознавание цилиндрических диаметров и повторяющихся отверстий.
- Распознавание PCD по центрам одинаковых цилиндрических отверстий.
- Автоматическая таблица размеров.
- Интерактивный офлайн 3D wireframe: rotate + zoom мышью или пальцем.
- STEP-сборки: PRODUCT, NEXT_ASSEMBLY_USAGE_OCCURRENCE, ITEM_DEFINED_TRANSFORMATION.
- Повторяющиеся компоненты располагаются по assembly transforms.
- BOM / количество вхождений.
- Export локального JSON engineering report.
- Web Worker для тяжёлого STEP parsing.
- Service Worker + manifest + локальные иконки + sample STEP.

## Встроенные тестовые модели

- `samples/sample_flange.step`: фланец Ø80 × 12, центральное Ø20, 6×Ø6 на PCD Ø60.
- `samples/sample_shaft.step`: ступенчатый вал Ø36 / Ø30 / Ø20 длиной 90.
- `samples/sample_assembly.step`: плита + 4 одинаковых болта с assembly transforms.

Кнопки **Фланец / Вал / Сборка** позволяют проверить ядро без своего файла.

## Важно про SolidWorks

`SLDPRT` и `SLDASM` — закрытые нативные форматы SolidWorks. Эта версия их определяет, но не декодирует. Для офлайн-ядра используйте экспорт из SolidWorks в STEP (`.step/.stp`). Import Core отделён от остальных модулей, поэтому нативный адаптер позже можно добавить отдельно.

## Граница текущей версии

v0.4.0 генерирует **инженерный производственный черновик**, а не автоматически утверждённый ГОСТ/ISO-документ. Геометрические размеры строятся из STEP детерминированно, но допуски, посадки, шероховатость, GD&T/PMI и технологические требования пока должны задаваться отдельно и проверяться конструктором.

Пока нет:

- полной тесселяции B-Rep в shaded mesh;
- точной проекции NURBS/B-Spline как производственной кривой;
- автоматического определения всех фасок, канавок, резьб и скруглений;
- PMI/GD&T/MBD AP242;
- редактирования импортированного feature tree;
- нативного SLDPRT/SLDASM decoding.

## Запуск

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080`.

## Тесты

```bash
npm test
```

Тесты проверяют B-Rep, габариты, PCD, assembly transforms, выбор главного вида, построение разреза, длины ступеней и smoke-test SVG Drawing Core.

## Архитектура

`Import Core → CAD/Topology Core → Recognition Core → Dimension Core → Drawing Core → Assembly Core`

Главный принцип: один источник точной геометрии используется для 3D, размеров, чертежа и будущей технологической проверки.
