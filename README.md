# ROZFOOD ENGINEERING STUDIO · OFFLINE CAD v0.8.0

## Tessellation Geometry Recognition

Эта сборка принимает **только `.SLDASM`** и работает полностью локально: без AI/API, без облачного CAD и без отправки модели на сервер.

### Что добавлено в v0.8.0

- сохранён нативный импорт `SLDASM → COMPINSTANCETREE + FaceTessellations`;
- сохранены матрицы вхождений и корректная сборочная 3D-сцена;
- добавлено собственное детерминированное ядро распознавания геометрии по mesh;
- распознаются **плоские поверхности**;
- распознаются **цилиндрические поверхности** через анализ нормалей + circle fit;
- цилиндры классифицируются как наружные поверхности или внутренние отверстия;
- строятся доминирующие осевые направления;
- из цилиндров формируются кандидаты размеров `Ø` и `L`;
- вкладка «Чертёж» строит первый геометрический TESS-чертёж вместо заглушки;
- режим «Объём» стал непрозрачнее, mesh-рёбра приглушены;
- экспорт JSON включает блок `recognition`.

### Контрольный файл

На `Сборка Барабана Глобино.SLDASM` ядро v0.8.0 получило:

- 17 BOM-позиций;
- 31 вхождение;
- 28 размещённых leaf-вхождений;
- 117 tess-блоков;
- 25 962 треугольника сборочной сцены;
- габарит около **476 × 1225 × 476 мм**;
- **209** анализируемых tess-face групп;
- **86** плоских поверхностей;
- **67** цилиндрических поверхностей;
- **36** внутренних цилиндрических поверхностей/отверстий;
- **8** осевых направлений.

Примеры кандидатов: `Ø476`, `Ø470`, `Ø468`, `Ø25`, длина осевого элемента около `1207 мм`.

### Ограничение

v0.8.0 работает по **FaceTessellations**, а не по точному Parasolid B-Rep. Поэтому распознанные технологические размеры помечаются **TESS / VERIFY** и должны быть подтверждены конструктором.
