# ROZFOOD ENGINEERING STUDIO · OFFLINE CAD v0.7.1

## SLDASM Assembly Transforms

Эта сборка принимает **только `.SLDASM`** и работает локально, без AI/API и серверного CAD.

### Что изменилось в v0.7.1

- читается `COMPINSTANCETREE` и дерево SolidWorks;
- читаются встроенные `FaceTessellations`;
- tess-блоки сопоставляются с leaf-моделями сборки;
- для каждого вхождения применяется его 4×4 `swTransform`;
- учитываются вложенные подсборки и накопленные трансформации;
- 3D теперь строится в **мировых координатах сборки**, а не наложением локальных тел;
- треугольники получают `componentId`, поэтому можно выбирать отдельное вхождение кликом;
- режим «Объём» сделан непрозрачнее, «Каркас» остаётся отдельным режимом;
- габариты считаются после размещения компонентов.

### Контрольный файл

На тестовой сборке `Сборка Барабана Глобино.SLDASM`:

- 17 BOM-позиций;
- 31 вхождение, из них 28 leaf-вхождений размещено в 3D;
- 14/14 leaf-моделей сопоставлено с тесселяцией;
- 117 tess-блоков;
- 16 926 исходных треугольников;
- 25 962 треугольника в итоговой сцене после размножения повторяющихся деталей;
- итоговый габарит сцены около **476 × 1225 × 476 мм**.

### Ограничение

Это всё ещё графическая тесселяция SolidWorks, а не Parasolid B-Rep. Для точного распознавания цилиндров, отверстий, фасок, резьб и допусков нужен следующий B-Rep слой.
