# ROZFOOD ENGINEERING STUDIO · OFFLINE CAD v0.7.0

## SLDASM Native 3D / FaceTessellations Core

Полностью локальный PWA-модуль для открытия **SolidWorks `.SLDASM`** без сервера, AI и внешнего CAD во время работы.

### Что реально умеет v0.7.0

- принимает только `.SLDASM` как входной SolidWorks-формат;
- распознаёт современный бинарный контейнер SolidWorks 2015+;
- локально извлекает нативные внутренние потоки сборки;
- читает `swXmlContents/COMPINSTANCETREE` и строит дерево компонентов, вхождения и BOM;
- извлекает встроенные `FaceTessellations/*`;
- декодирует вершины, нормали и triangle-strip группы;
- переводит координаты тесселяции из метров в миллиметры;
- строит реальную 3D-сцену прямо в браузере;
- режимы 3D: **Объём** и **Каркас**;
- показывает габариты X / Y / Z по тесселяции;
- сохраняет сборочный детализированный BOM-чертёж и JSON-отчёт;
- работает офлайн после кэширования PWA.

### Проверка на реальной сборке

Внешний контрольный `.SLDASM` успешно декодирован:

- 17 BOM-позиций;
- 31 вхождение;
- 68 найденных stream-записей;
- 117 декодированных tessellation face blocks;
- 20 652 вершины;
- 16 926 треугольников;
- габарит тесселяции: примерно **1271.763 × 663.000 × 476.000 мм**.

Контрольный файл в дистрибутив **не включён**.

## Важное ограничение

v0.7.0 декодирует **встроенную графическую тесселяцию SolidWorks**, поэтому модель можно полноценно увидеть и вращать. Это **не Parasolid B-Rep**.

Следовательно, габариты по mesh доступны уже сейчас, но точное семантическое распознавание цилиндров, отверстий, фасок, радиусов, резьб и построение производственного чертежа из нативного SolidWorks потребует следующего B-Rep/topology слоя.

Отдельный `.SLDPRT` как входной файл намеренно не поддерживается. Ссылки на `.SLDPRT` внутри самой сборки могут отображаться в BOM как состав `.SLDASM`.

## Архитектура

`SLDASM → Modern chunk streams → COMPINSTANCETREE + FaceTessellations → triangle strips → ROZFOOD 3D Viewer`

Всё декодирование выполняется на клиенте через Web Worker. Сжатые SolidWorks stream payloads распаковываются локально через Web Compression Streams API (`deflate-raw`). Для Safari/iOS требуется версия 16.4 или новее.
