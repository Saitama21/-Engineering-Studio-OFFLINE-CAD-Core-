# Reference Drawing Rules v0.9.0

Эталонная логика сборочного листа, перенесённая в алгоритм ROZFOOD без встраивания исходного PDF:

- продольный общий вид с общим осевым габаритом;
- цепочка осевых размеров между кольцами/торцевыми плоскостями;
- торцевой вид с основными диаметрами;
- осевые линии;
- разрез A–A;
- сечение/вид B–B;
- локальные увеличенные виды C и D;
- сборочный изометрический вид;
- позиционные выноски;
- спецификация/BOM;
- основная надпись, лист и масштаб.

Правила применяются к любой SLDASM-сборке, если распознанная геометрия позволяет построить соответствующий вид. Значения размеров берутся из модели, а не из эталонного PDF.
