# SLDASM Native Reference Adapter v0.6.2

Входной формат приложения — только `.SLDASM`.

Адаптер локально распознаёт контейнер SolidWorks, ищет ссылки на компоненты/подсборки, считает экземпляры и формирует дерево сборки/BOM.

Текущий уровень — reference metadata. Нативная 3D-геометрия SolidWorks пока не декодируется; для неё требуется отдельный SLDASM geometry decoder.
