# SLDASM Assembly Transform Decoder v0.7.1

Главное изменение: FaceTessellations больше не рисуются как единый набор локальных тел.

1. COMPINSTANCETREE даёт дерево моделей и 4×4 матрицы `swTransform`.
2. Локальные tess-блоки сопоставляются с leaf-моделями по их `swBoundingBox` и порядку модели в контейнере.
3. Для каждого вхождения матрица разворачивается рекурсивно по дереву сборки.
4. Треугольники копируются в мировые координаты и получают `componentId`, поэтому клик по детали теперь связан с конкретным вхождением.
5. Габарит сцены считается уже после размещения компонентов.

Формат остаётся offline-only и принимает только `.SLDASM`. Точный Parasolid B-Rep пока не декодируется.
